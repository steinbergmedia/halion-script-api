getMediaBayAttributes

getMediaBayAttributes(filename)

(Since HALion 7.5.0)

Description

Reads the MediaBay attributes from a specified VST preset or audio file.

Arguments

ArgumentDescriptionValue Type
filenameThe absolute path and name of the VST preset or audio file.string

Return Values

Returns a table containing the MediaBay attributes of the specified file. Each entry in the table is a key-value pair, where the key is the attribute name and the value is the metadata stored in MediaBay.

Raises an error if the file cannot be found or is invalid.

MediaBay Attributes

getMediaBayAttributes can read any of the following attributes.

The following attributes are stored in VST presets and allow for browsing them in MediaBay. They can be written with savePreset and setMediaBayAttributes.

AttributeValueValue Type
MediaAuthor"Author"string
MediaComment"Comment"string
MediaKeywords"Keywords"string
MediaLibraryManufacturerName"ManufacturerName"string
MediaLibraryName"LibraryName"string
MediaRating"Number", 1 to 5 stars.string
MusicalArticulations"Articulation1|Articulation2|..."string
MusicalCategory"Category"string
MusicalGmSound"Number", the GM program number.string
MusicalInstrument"Category|Subcategory"string
MusicalMoods"Mood1|Mood2|..."string
MusicalProperties"Property1|Property2|..."string
MusicalRootKey"RootKey"string
MusicalSignature"4/4"string
MusicalStyle"Style"string
MusicalSubStyle"Style|Substyle"string
MusicalTempo"Number", the tempo in BPM.string

The following attributes can only be written with setMediaBayAttributes. They are needed for audio files that come with Cubase, such as loop sets. VST presets must not use them.

AttributeValueValue Type
MediaFamily"Family"string
MediaGenre"Genre"string
MusicalBeats"Number", beat count derived from the tempo and sample length.number
MusicalCharacter"Character1|Character2|..."string

The following attributes are written exclusively with the arguments of savePreset. setMediaBayAttributes cannot modify them.

AttributeValueValue Type
PlugInName"Name", set with the plugin argument of savePreset.string
VST3UnitTypePath"program" or "program/layer", set with the attr argument of savePreset.string

❕ See MediaBay Guideline for more information about the attributes and how to use them.

Example

posStart, posEnd = string.find(getUserSubPresetPath(), "Steinberg/")
fileLocation = string.sub(getUserSubPresetPath(), 1, posEnd)

defineParameter("FileName", nil, "test.vstpreset")
defineParameter("ReadAttributes", nil, false,
    function() if ReadAttributes then onReadAttributesChanged() end end)
defineParameter("WriteAttributes", nil, false,
    function() if WriteAttributes then onWriteAttributesChanged() end end)

function onReadAttributesChanged()
    local attrs = getMediaBayAttributes(fileLocation..FileName)
    for k, v in pairs(attrs) do
        print(k, "=", v)
    end
    ReadAttributes = false
end

function onWriteAttributesChanged()
    local newAttrs = {
        MediaRating       = "3",
        MusicalStyle      = "Electronica/Dance",
        MusicalSubStyle   = "Electronica/Dance|Synthwave",
        MusicalProperties = "Dark|Soft",
    }
    setMediaBayAttributes(fileLocation..FileName, newAttrs)
    WriteAttributes = false
end
