createWavetable

createWavetable{arguments}

(Since HALion 7.5.10)

Description

Function to create a Wavetable table from an audio file. You specify the audio file with the AudioFile object that is returned by the AudioFile.open function. The createWavetable function can be configured with named arguments. The named arguments are optional and if called without, createWavetable will be executed with its default settings. The .linkEnvelope field is initialized to true for all generated waves.

❕ Creating a wavetable can take a long time. Therefore, it is recommended to use the callback argument, which runs createWavetable in a parallel thread and performs the required pitch analysis automatically.

Available in: Controller.

Arguments

ArgumentDescriptionValue Type
callbackAn optional callback function called with the AudioFile object and the resulting wavetable table as arguments once analysis is complete. If omitted, createWavetable runs synchronously in the current thread and returns the wavetable directly. In this case, the pitch analysis required for the wavetable analysis is not performed — you must call analyzePitch for the audio file in advance. If provided, createWavetable runs asynchronously in a parallel thread and performs the required pitch analysis itself; use getWavetableCreationProgress to monitor progress and cancelWavetableCreation to abort.function, optional
startThe start position in samples within the audio file from which wave extraction begins. Together with length, this defines the region of the sample used for placing wave extraction markers. The default is 0 (the beginning of the audio file).number, optional
lengthThe length in samples of the region used for wave extraction, measured from start. Set to 0 or a negative value to extend the region to the end of the audio file. The default is 0 (use all samples from start to the end).number, optional
analyzeWavetableWhen true (the default), waves are automatically analyzed and their spectral data populated after extraction. When false, wave markers are created but analysis is skipped — useful if you intend to call analyzeWavetable manually later or want to inspect the structure before committing to analysis.bool, optional
creationModeDetermines how wave extraction markers are distributed within the specified range in the audio file. Options: Equal Distance (1) — markers spaced evenly; Exponential (2) — markers spaced with exponential distribution, denser at the start; Spectral (3) — markers placed at points of significant spectral change; Spectral Voiced (4) — like Spectral but focuses on voiced (pitched) content; Overlap-Add (5) — uses overlapping analysis windows, controlled by overlap. The default is Equal Distance (1). See Wavetable Enumeration Types.enum or number, optional
numWavesThe number of wave extraction markers to place within the specified range in the audio file. Only for Equal Distance and Exponential creation modes. The default is 1.number, optional
thresholdThe minimum signal level (in dB) required for a wave extraction marker to be placed. Only used by the Spectral and Spectral Voiced creation modes. Regions with levels below this threshold are ignored. Raise this value to focus on louder, more prominent content; lower it to capture quieter regions. The default is -40 dB.number, optional
sensitivityControls how sensitive the analysis is to spectral changes when placing wave extraction markers. Only used by the Spectral and Spectral Voiced creation modes. Higher values cause markers to be placed at more subtle spectral transitions, resulting in more waves; lower values require more pronounced changes before a marker is added. The value is in percent and the default is 25.number, optional
overlapSets the overlap between analysis windows when using the Overlap-Add creation mode, has no effect in other creation modes. Higher overlap values capture more detail and produce more wave markers; lower values capture less detail and yield fewer markers. Options: None (1), 2x (2), 4x (3), 8x (4), 16x (5). The default is 4x (3). See Wavetable Enumeration Types.enum or number, optional
includeWindowControls whether analysis windows are constrained to fit fully within the sample boundaries. When false (the default), the center of the analysis window is placed exactly at the start and end of the range, meaning half the window may extend outside the sample. When true, markers are positioned so the entire analysis window stays within the sample — use this when importing wavetable samples where each equal-length segment represents a distinct waveform.bool, optional
channelSelectionSelects which channel(s) of the audio file are used for wave creation. Multi (1) analyzes all available channels; Sum (2) mixes all channels together before analysis; the remaining options select a single discrete channel. The default is Multi (1). The selected channel must exist in the source file. See Wavetable Enumeration Types.enum or number, optional
winTypeThe window function applied during spectral analysis. Different window types affect side lobe suppression, which changes how the analyzed spectrum sounds. Options: Rectangular (1), Cosine (2), Bartlett (3), Hanning (4), Hamming (5), Blackman (6), Blackman-Harris (7). Blackman (6, default) is a good general-purpose choice. Rectangular (1) has high side lobes, causing energy from strong partials to bleed into neighboring bins. Blackman-Harris (7) offers the strongest side lobe suppression. Experiment to find what works best for your material. See Wavetable Enumeration Types.enum or number, optional
winSizeModeSpecifies how the window size is determined during spectral analysis. Auto (1, the default) derives the window size from the detected fundamental frequency of each channel. Fixed Individual (2) uses the per-channel sizes specified in winSize[n]. Fixed Common (3) uses the same winSize[1] value for all channels. See Wavetable Enumeration Types.enum or number, optional
winSize[n]The analysis window size in samples for the n-th channel (e.g., winSize[1] for the left channel, winSize[2] for the right, up to six channels). Only used when winSizeMode is set to Fixed Individual or Fixed Common. The maximum is 8192 samples; the default is 512.number, optional
winCrossfadeThe crossfade duration applied to the edges of the Rectangular window, expressed as a percentage of the analysis window size. Softens the hard boundaries of the Rectangular window to reduce its side lobes. The default is 10.number, optional
spectralEnvResDefines how closely the spectral envelope follows the distribution of the magnitudes across the spectrum. The spectral envelope shapes the formant filter: higher values produce a smoother filter curve with less pronounced formants, while lower values cause the filter curve to track spectral levels more tightly, yielding a more detailed formant response. The default is 500 Hz, which is suitable for most audio content.number, optional
freqLimitAllows you to limit the playback to the frequency range that the wave actually uses. Any frequencies above this limit are skipped during synthesis, which can lower CPU load. Raise this value to preserve more high-frequency content; lower it to save processing power. The default is 20000 Hz.number, optional

Return Values

Returns a Wavetable table.

Example

creationModes = { "EqualDist", "Exponential", "Spectral", "SpectralVoiced", "OverlapAdd", }
overlapModes = { "None", "2x", "4x", "8x", "16x", }
channelSelectionModes = { "Multi", "Sum", "Left", "Right", "Center", "LFE", "RearLeft", "RearRight", }
winTypes = { "Rectangular", "Cosine", "Bartlett", "Hanning", "Hamming", "Blackman", "BlackmanHarris", }
winSizeModes = { "Auto", "FixedIndividual", "FixedCommon", }

defineParameter { name = "StartProcess", default = false, onChanged = function() if StartProcess then onStart() end end }
defineParameter { name = "CancelProcess", default = false}
defineParameter { name = "AnalyzeWavetable", default = true }
defineParameter { name = "CreationMode", default = wavetable.CreationMode.equalDist, strings = creationModes }
defineParameter { name = "NumWaves", default = 1, min = 0, max = 0x80000000 - 1, increment = 1 }
defineParameter { name = "Threshold", default = -40, min = -96, max = 0, increment = 0.1 }
defineParameter { name = "Sensitivity", default = 25, min = 1, max = 100, increment = 0.1 }
defineParameter { name = "Overlap", default = wavetable.CreationOverlap.mode4x, strings = overlapModes }
defineParameter { name = "IncludeWindow", default = false }
defineParameter { name = "SampleStart", default = 0, min = 0, max = 1000, increment = 1 }
defineParameter { name = "SampleLength", default = 0, min = 0, max = 1000, increment = 1 }
defineParameter { name = "ChannelSelection", default = wavetable.ChannelSelection.multi, strings = channelSelectionModes }
defineParameter { name = "WinType", default = wavetable.WinType.blackman, strings = winTypes }
defineParameter { name = "WinSizeMode", default = wavetable.WinSizeMode.auto, strings = winSizeModes }
defineParameter { name = "WinSizeCh1", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinSizeCh2", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinSizeCh3", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinSizeCh4", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinSizeCh5", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinSizeCh6", default = 512, min = 0, max = 8192, increment = 0.01 }
defineParameter { name = "WinCrossfade", default = 10, min = 0, max = 100, increment = 0.1 }
defineParameter { name = "SpectralEnvRes", default = 500, min = 250, max = 1000, increment = 0.1 }
defineParameter { name = "FreqLimit", default = 20000, min = 10, max = 22000, increment = 1 }
 
function onStart()
    zones = this.parent:findZones(true)
    for i, zone in ipairs(zones) do
		local function onFinished(afile, wt)
			print("Progress: 100%")
			if wt then
				print("Wavetable of "..afile.fileName.." created.")
				print("Number of Waves: "..#wt)
				zone:setParameter("ZoneType", 4)
				zone:setWavetable(1, wt)
			end
		end
		local samplePath = zone:getParameter("SampleOsc.Filename")
		local afile = AudioFile.open(samplePath)
		if afile then
			local startSamples = SampleStart * afile.rate/1000
			local lengthSamples = SampleLength * afile.rate/1000
			local winSize = {   WinSizeCh1,
			                    WinSizeCh2,
			                    WinSizeCh3,
			                    WinSizeCh4,
			                    WinSizeCh5,
			                    WinSizeCh6 }
			print("Create Wavetable "..samplePath)
			afile:createWavetable{
				callback = onFinished,
				start = startSamples,
				length = lengthSamples,
				analyzeWavetable = AnalyzeWavetable,
				creationMode = CreationMode,
				numWaves = NumWaves,
				threshold = Threshold,
				sensitivity = Sensitivity,
				overlap = Overlap,
				includeWindow = IncludeWindow,
				channelSelection = ChannelSelection,
				winType = WinType,
				winSizeMode = WinSizeMode,
				winSize = winSize,
				winCrossfade = WinCrossfade,
				spectralEnvRes = SpectralEnvRes,
				freqLimit = FreqLimit,
			}
			while afile:getWavetableCreationProgress() < 1 do
				if CancelProcess then
					afile:cancelWavetableCreation()
					break
				end
				local progress, errorMessage = afile:getWavetableCreationProgress()
				if errorMessage then
					print(errorMessage)
					break
				else
					local progressPercent = 100 * progress
					print(string.format("Progress: %2d%%", progressPercent))
					wait(2000)
				end
			end
			if CancelProcess then
				CancelProcess = false
				print("Wavetable creation canceled!")
				break
			end
		end
	end
	print("Wavetable creation finished.")
	StartProcess = false
end
