savePreset

savePreset(filename, layer, plugin, attr)

(Since HALion 7.0)

Description

Saves the specified Layer element as a VST preset to disk. The preset format is determined by the plugin argument, which also defines which Steinberg instrument can load the resulting .vstpreset file. If MediaBay attributes are provided through attr, they are written into the preset.

Available in: Controller.

Arguments

ArgumentDescriptionValue Type
filenameThe absolute path and name of the file location where the VST preset is saved.string
layerSpecifies the Layer element to be saved as VST preset.Layer
pluginSpecifies the target plug‑in format for the VST preset. Valid values are "H7" (HALion 7) and "HS" (HALion Sonic). Only the selected plug‑in can load the saved VST preset.string, optional
attrIf set to program the VST preset is saved as a program preset. Otherwise, the argument may contain a table of MediaBay attributes and values that will be written to the VST preset. If omitted, a layer VST preset is saved.string, optional

MediaBay Attributes

MediaBay attributes are stored in VST presets and allow for browsing them in MediaBay. You can set the following attributes with this function or with setMediaBayAttributes.

AttributeValueValue Type
MediaAuthor"Author"string
MediaComment"Comment"string
MediaKeywords"Keywords"string
MediaLibraryManufacturerName"ManufacturerName"string
MediaLibraryName"LibraryName"string
MediaRating"Number", 1 to 5 stars.string
MusicalArticulations"Articulation1|Articulation2|..."string
MusicalCategory"Category"string
MusicalGmSound"Number", the GM program number.string
MusicalInstrument"Category|Subcategory"string
MusicalMoods"Mood1|Mood2|..."string
MusicalProperties"Property1|Property2|..."string
MusicalRootKey"RootKey"string
MusicalSignature"4/4"string
MusicalStyle"Style"string
MusicalSubStyle"Style|Substyle"string
MusicalTempo"Number", the tempo in BPM.string

The following attributes are written exclusively with the arguments of savePreset. setMediaBayAttributes cannot modify them.

AttributeValueValue Type
PlugInName"Name", set with the plugin argument of savePreset.string
VST3UnitTypePath"program" or "program/layer", set with the attr argument of savePreset.string

❕ See MediaBay Guideline for more information about the attributes and how to use them.

Example

posStart, posEnd = string.find(getUserSubPresetPath(), "Steinberg/")
fileLocation = string.sub(getUserSubPresetPath(), 1, posEnd)

defineParameter("FileName", nil, "test.vstpreset")
defineParameter("SavePreset", nil, false, function() if SavePreset then onSavePresetChanged() end end)

setScriptExecTimeOut(20000)

attr = {MediaRating = "3", MusicalProperties = "Soft|Bright|Rich", VST3UnitTypePath = "program",}

function onSavePresetChanged()
	FileName = fileLocation..FileName
	local layer = this.parent:getLayer()
	local saved = savePreset(FileName, layer, "HS", attr)
	print(saved)
	SavePreset = false
end
